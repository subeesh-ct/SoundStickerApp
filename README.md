# 🔊 Sound Sticker

**WhatsApp Sound Sticker Floating Tool for Android**

![Platform](https://img.shields.io/badge/Platform-Android-3DDC84?style=flat-square&logo=android&logoColor=white)
![Open Source](https://img.shields.io/badge/Open%20Source-100%25-1D63ED?style=flat-square)
![Privacy](https://img.shields.io/badge/Processing-100%25%20Local-success?style=flat-square)

Create and send WhatsApp **Sound Stickers** directly from your Android phone using a clean floating side button—no PC or external server required.

---

## ⚙️ How It Works

1. **Local WhatsApp Web Engine:** Connects to `web.whatsapp.com` inside an isolated Android `WebView` directly on your device.
2. **On-Device Conversion:** Combines your selected **Video / GIF** with **Video Audio, Custom Audio, or Live Mic Recording** locally on your phone.
3. **Floating Side Tool:** Runs a lightweight floating bubble over WhatsApp so you can build and send sound stickers without leaving your chat.
4. **Smart Chat Detection:** Automatically detects the currently open WhatsApp chat, or lets you send to **Myself** or enter a phone number manually.

---

## ✨ Features

* **3 Audio Modes:** Use the video's original sound, pick any audio file, or record your voice live via microphone.
* **Pinch-to-Zoom QR Linking:** Built-in zoomable QR / Phone Code linking screen with no annoying auto-refresh.
* **Auto-Hide Option:** Enable *"Show only inside WhatsApp"* to automatically hide the floating button in other apps.
* **Lightweight & Minimal:** Clean dark UI with instant ON/OFF control and quick notification toggle.

---

## 🚀 Setup & Usage

1. Download and install the latest APK from the **[Releases](../../releases)** section.
2. Open **Sound Sticker** and complete the 4 setup steps:
   * **Link WhatsApp:** Scan the QR code or link using your phone number.
   * **Floating Pop-up Permission:** Allow display over other apps.
   * **Auto-Detect Chat (Accessibility):** Enable to automatically detect open WhatsApp chats.
   * **Mic, Contacts & Notification:** Grant required runtime permissions.
3. Tap **TURN ON** to activate the floating side button.
4. Open any WhatsApp chat, tap the floating button, pick a video/GIF + audio, and hit **Send**.

---

## 🔒 Privacy & Open Source

This project is **100% Open Source**. Every line of code is publicly available in this repository for anyone to inspect and build directly.

* **No External Servers:** Your WhatsApp session, media files, and chats never leave your device.
* **No Tracking or Data Collection:** Zero analytics, zero ads, zero third-party data sharing.

### Why Permissions Are Required

| Permission | Purpose |
| :--- | :--- |
| **Display Over Other Apps** | Shows the floating side button and sticker creator pop-up. |
| **Accessibility Service** | Only reads the active WhatsApp chat header to auto-fill the recipient. |
| **Microphone** | Records voice audio when using the *Record Mic* option. |
| **Storage / Media** | Picks videos, GIFs, and audio files from your device. |
| **Contacts** | Matches chat names with contact numbers when needed. |
| **Notifications** | Displays the persistent status notification with a quick *Turn OFF* button. |
